# Diseño

## Sistema visual

| | |
|---|---|
| Tipografías | Bodoni Moda (títulos) · Archivo (interfaz) · IBM Plex Mono (datos) |
| Papel | `#FAF9F7` claro · `#131311` oscuro |
| Tinta | `#14130F` |
| Series de datos | `#1F3A6E` · `#B8503D` · `#1E7A52` · `#C08A1E` · `#2D5BA8` |
| Acento IA | `#FFAFA3` (salmón) |

**La regla del salmón.** Lo negro es medido. Lo salmón es calculado o interpretado por un modelo. Se
sostiene en la app y en la presentación.

**La etapa no se pinta de color.** Hay cinco etapas y el color ya está ocupado por la ropa, que es el
dato que la usuaria vino a ver. La etapa se codifica como posición en una pista. La interfaz es monocroma
para que el único color de la pantalla sea el de las prendas.
